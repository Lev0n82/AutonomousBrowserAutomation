Connection settings

The bridge listens only on this computer. Follow these steps to generate its token and link this extension.

Generate and link the bridge token

  1. Start the bridge — the token is generated automatically. In PowerShell run . The launcher writes a random session token to %LOCALAPPDATA%\OllamaComet\bridge.token and reuses it across bridge restarts.
  2. Copy the token. Open that file in Notepad and copy the single line inside it. It authorizes this extension against 127.0.0.1:11435 only — it is not your Ollama Cloud API key, and never share or commit it.
  3. Paste and save. Keep Bridge URL as http://127.0.0.1:11435, paste the token into Bridge token, then select Save.
  4. Verify the link. Select Test connection; it should report “Connection successful.”
  5. Open the assistant.

Running revokes the current token; the next launch generates a replacement, which you then paste here again.
